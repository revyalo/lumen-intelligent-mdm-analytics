# Lumen — Intelligent MDM & Analytics v0.1.0

Prepared release notes. Publication is pending owner approval and GitHub-hosted CI.

A local data intelligence workspace covering exploratory analysis, quality scoring, DuckDB business analytics/RFM, reversible master-data review and descriptive machine learning.

- Eight Streamlit sections, reusable Python modules and exportable evidence reports.
- Reproducible synthetic distributor data, with separate master observations, transactions and evaluation-only labels.
- Exact/fuzzy entity resolution, explicit conflict review, reversible decisions and field-level lineage.
- Seeded K-Means with silhouette/RFM comparisons, plus statistical and Isolation Forest diagnostics.
- 41 locally passing tests, two rerun notebooks and repeated experiments across up to 194,363 rows.
- MIT-licensed original code/assets, documented third-party terms and publication hygiene checks.

Semantic matching is an optional unexecuted extension; no embedding model or predictive-performance claim is included. Synthetic benchmarks are descriptive. This is a trusted local analyst application, without production multiuser/authentication guarantees.

See `docs/RELEASE_AUDIT.md` for executed evidence, fixed preparation issues and remaining gates. GitHub CI must pass on the intended release revision before public publication is approved.
